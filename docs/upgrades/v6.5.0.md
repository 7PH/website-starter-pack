# v6.5.0

- **Released:** 2026-11-20
- **Summary:** The CMS photo library and picker hold thousands of photos: search, used / unused filter, folders, bulk delete and move, sorts and infinite scroll.

## Required migration

Run it **before** deploying the new code, in every app (CMS on or off: `create_all` made the `cms_media` table everywhere). The new code reads a `folder` column wherever a photo is loaded, public pages included. The migration only adds a column and two indexes, so the old code runs fine with it.

```bash
npm run db-migrate -- app/backend/migrations/2026-11-20-v6.5.0-cms-media-library.sql
```

## New Features

- Search on file name and description, in the library and the picker
- Filter by used on the site / not used / used without description. The details panel lists the pages showing the photo, and thumbnails show how many pages use it
- Folders, one per photo: set in the details panel or in bulk, filterable in the library and the picker
- Multi-select in the library: bulk delete and bulk move to a folder. "Select all unused" covers the whole filtered library. Photos shown on a page are never deleted
- Sort by newest, oldest or name. The picker opens with photos used on the site first
- Photos load 60 at a time as you scroll, thumbnails at the smallest generated width
- Missing description warnings (banner and grid dot) only count photos shown on a page
- `POST /cms/media` takes an optional `created_at` form field, so an import script can keep each photo's original date. Future dates are refused

## New Core Files

- `app/frontend/components/cms/CmsMediaFilterBar.vue` (search, sort, usage and folder filters, shared by the library and the picker)
- `app/frontend/components/cms/CmsMediaLoadMore.vue` (loads the next page when scrolled into view)
- `app/backend/migrations/2026-11-20-v6.5.0-cms-media-library.sql`

## Upgrade Notes

No breaking changes for app-owned code, once the migration has run:
- `useCmsMediaLibrary()` takes an optional filters ref. Calls without it keep working
- `CmsMediaGrid` items are now `CmsMediaLibraryItem` (a `CmsMediaRead` with `usage_count`)
- `GET /cms/media/{id}` returns the photo with `used_by`, the pages showing it
