## v1.0.3 — 2026-03-08

Bug fixes only.

### Bug Fixes

- **`DEFAULT_LOCALE` now works**: setting `DEFAULT_LOCALE=fr` in `.env` correctly
  defaults new visitors to French, while still allowing users to switch language.
  Previously the env var was defined but never passed to the frontend or used anywhere.
- **`ConversationType`**: changed from `(str, enum.Enum)` to `enum.StrEnum` to fix a backend lint warning.

### Upgrade Notes

No breaking changes.
