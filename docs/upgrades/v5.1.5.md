# v5.1.5

- **Released:** 2026-09-13
- **Summary:** Patch. A failed token refresh no longer logs the user out unless the token is actually dead, and sessions now last 30 days.

## Upgrade Notes

**No action required.** No schema, API, or migration changes.

Sessions are longer: `JWT_ACCESS_TOKEN_EXPIRE_MINUTES` goes from 2 days to 30. It is sliding, so every page load extends it, and there is no refresh token — this constant is the whole session length. Tokens issued before the upgrade keep their old 2-day expiry until they are refreshed.

## Bug Fixes

### A backend blip logged the user out

`refreshToken()` called `logout()` on any error, so an unreachable backend (browser opened offline, deploy in flight) wiped the token from `localStorage` and forced a real re-login. Only a 401 logs out now; network errors and 5xx leave the session alone.
