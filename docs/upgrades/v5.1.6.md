## Upgrade Notes

**No action required.** No schema, API, or migration changes. The email goes through Mailgun like the others, so it is skipped when `MAILGUN_API_KEY` is unset.

## Bug Fixes

### Admin replies never reached the user

`admin_send_message` ended on a TODO, so a user only saw a reply if they happened to open `/messages`. The user who opened the conversation now gets an email linking to `/messages/{id}`. It is skipped when that user is gone, has no email (access-code accounts) or is soft-deleted, and a send failure is logged without blocking the reply.

The sitemap e2e test also asserts the sitemap's shape instead of specific URLs, so sub-apps with their own pages no longer fail it.
