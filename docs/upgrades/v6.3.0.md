# v6.3.0

- **Released:** 2026-11-18
- **Summary:** An item in `config/admin-nav-ext.ts` with the same route as a core admin nav item now replaces it, so apps can relabel, regroup or hide core sidebar entries.

## New Features

Give a `PROJECT_ADMIN_NAV` item the `to` of a core item to replace it. Add `condition: () => false` to hide it. Only the sidebar entry goes away, the page stays reachable. Eg to hide the core Orgs entry when your app has its own organizations admin:

```ts
export const PROJECT_ADMIN_NAV: AdminNavItem[] = [
    { label: 'Orgs', icon: 'i-lucide-building-2', to: '/admin/organizations', condition: () => false },
];
```

## Upgrade Notes

No breaking changes. Apps whose project items don't share a route with a core item see no change. If one does today, it now replaces the core entry instead of showing twice.
