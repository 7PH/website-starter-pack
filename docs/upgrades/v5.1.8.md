# v5.1.8

- **Released:** 2026-09-25
- **Summary:** Patch. The frontend prod build gets a 4 GB heap, so larger sub-apps no longer run out of memory while building.

## Upgrade Notes

**No action required.** No schema, API, or migration changes. Only `app/frontend/Dockerfile.prod-node` and `app/frontend/Dockerfile.prod-nginx` changed. The build host needs about 4 GB of free memory for the frontend build step.

## Bug Fixes

### Prod build ran out of memory

Since the @nuxt/ui 4.11 bump in v5.0.0, `nuxt build` can exceed Node's default ~2 GB heap while Nitro bundles the server (`FATAL ERROR: Reached heap limit`). The starterpack itself stays under the limit, but heavier sub-apps did not. The build step now runs with `NODE_OPTIONS=--max-old-space-size=4096`; the running container is unchanged.
