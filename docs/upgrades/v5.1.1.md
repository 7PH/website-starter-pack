# v5.1.1

- **Released:** 2026-09-07
- **Summary:** Patch. Scheduled cron tasks never ran; they now start from the app lifespan.

## Upgrade Notes

**No action required.** No schema, API, or migration changes. Task registration keeps the same signature, so sub-app task modules need no edits.

## Bug Fixes

### Scheduled tasks never ran

Cron tasks were wired with startup event hooks, which FastAPI ignores when the app uses a lifespan. No scheduler ever started, so every cron task silently did nothing. The lifespan now starts and stops them.
