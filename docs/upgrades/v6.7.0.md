# v6.7.0

- **Released:** 2026-11-22
- **Summary:** The CMS photo library accepts GIF, and animated GIF and WebP uploads stay animated.

## New Features

- GIF uploads are accepted. A static GIF is handled like any other photo
- Animated GIF and WebP are stored as animated WebP, with their frame timings and loop count. URLs, srcset, focal point and crops work as for any photo
- Animations get the 480 and 960 widths only, at most 300 frames and 50 MP across all frames (~200 MB of memory at worst). Anything bigger is refused with a clear message (en/fr)
- The dropzone copy mentions GIF

## Upgrade Notes

No breaking changes, no migration. Photos uploaded before stay as they are: an animation uploaded earlier was flattened to its first frame, upload it again to animate it.
