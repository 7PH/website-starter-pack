# v1.3.0

- **Released:** 2026-04-12
- **Summary:** Replace brittle E2E setup with health check polling and a minimal smoke test that doesn't constrain sub-app UI.

## New Core Files

- `scripts/_core/wait-for-services.sh` - polls a health check URL instead of `sleep 30`
- `app/frontend/e2e/smoke.spec.ts` - minimal stack smoke test (replaces `auth.spec.ts`)

## Removed Core Files

- `app/frontend/e2e/auth.spec.ts` - moved out of core; sub-apps should add their own auth E2E tests

## Bug Fixes

- CI `e2e.yml` no longer uses `sleep 30`; polls the healthcheck endpoint with a 120s timeout
- Playwright timeout bumped from 30s to 60s, CI gets 1 retry, expect timeout raised to 10s

## Upgrade Notes

- `auth.spec.ts` is deleted by the core sync. If you had customized it, back up your version first. You can re-add your own auth E2E tests as non-core files in `app/frontend/e2e/`.
- No other breaking changes.
