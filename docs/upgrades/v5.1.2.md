# v5.1.2

- **Released:** 2026-09-08
- **Summary:** Patch. Account settings showed raw i18n keys as tab labels, and account error toasts leaked the backend's English text into translated UIs.

## Upgrade Notes

**No action required.** No schema, API, or migration changes. `withToast` keeps the same signature; its new default only applies to 429s, and a call site's own `statusKeys` still wins.

## Bug Fixes

### Account settings tabs showed raw i18n keys

`core.account.tabs.*` was referenced by the account page but never defined, so the tab strip rendered the key names instead of labels. The five keys are now in `core-en.json` and `core-fr.json`.

### English backend errors reached translated toasts

A wrong current password showed "Invalid current password" and a rate-limited request showed "Too many requests. Please try again later.", because the toast falls back to the error's own message. `withToast` now maps 429 to `core.errors.tooManyRequests` by default, and the password form maps its 401 to `core.account.password.wrongCurrent`.
