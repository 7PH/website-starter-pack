## Bug Fixes

### Forgot-password message promised an email that never comes

To avoid account enumeration, the reset endpoint answers the same for unknown emails, but the toast said "Email de réinitialisation envoyé". Someone typing an address with no account then waited for nothing. It now reads "Vérifiez votre boîte mail / Si un compte existe pour cette adresse, vous allez recevoir un lien valable 4 heures. Pensez à regarder dans les spams." (English updated the same way).
