# v5.1.4

- **Released:** 2026-09-12
- **Summary:** Patch. Four frontend fixes around logout, the account tabs and the premium page.

## Upgrade Notes

**No action required.** No schema, API, or migration changes.

## Bug Fixes

### Logging out moved the user off a public page

Logging out always sent the user to the home page. It now keeps them where they are unless the page needs auth.

### Account tabs were clipped to a single initial on mobile

Every tab label collapsed to one character on a phone. The strip now scrolls instead.

### `?tab=` with an unknown value stayed in the URL

An unrecognised tab query left the URL disagreeing with the screen. It is now dropped.

### Premium page rendered with Stripe disabled

`/premium` still worked with `STRIPE_ENABLED` off. It now returns a 404.
