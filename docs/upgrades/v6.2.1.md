# v6.2.1

- **Released:** 2026-11-15
- **Summary:** Core backend tests pass in apps that run with `REAL_NAMES_ENABLED=false`, and the docs run `convert-models.sh` with `bash`.

## Bug Fixes

- Core backend tests read `REAL_NAMES_ENABLED` from the app's env, so 6 of them failed in apps with names off. They now pin it to its default
- `scripts/_core/convert-models.sh` wasn't executable, so `./scripts/_core/convert-models.sh` gave "Permission denied". Run it with `bash scripts/_core/convert-models.sh`

## Upgrade Notes

No breaking changes. Core sync keeps the old file mode on existing apps, so keep using `bash scripts/_core/convert-models.sh`.
