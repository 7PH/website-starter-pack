# v1.0.4 — 2026-03-10

Fix Traefik incorrectly enabling TLS when `USE_TLS=false`.

## Bug Fixes

- **Traefik TLS check**: `dynamic.core.yml` used `{{ if env "USE_TLS" }}` which evaluates to true for any non-empty string, including `"false"`. Changed to `{{ if eq (env "USE_TLS") "true" }}` so TLS is only enabled when the value is explicitly `"true"`.

## Upgrade Notes

No breaking changes.
