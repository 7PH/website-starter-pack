## Bug Fixes

### Compound names lost words in the bulk import

With the space separator, each line kept only its first two words, so "DE LA TOUR Hugo" became first name "LA", last name "DE", and "Jean Pierre MARTIN" lost MARTIN. The line is now cut where the ALL-CAPS surname meets the rest ("DE LA TOUR" + "Hugo", "Jean Pierre" + "MARTIN"). Lines without an ALL-CAPS run are cut after the first word, keeping every word.
