# v5.1.0

- **Released:** 2026-09-05
- **Summary:** Minor. The static media host nginx config now has extension points so sub-apps can add their own config without touching the core file.

## New Core Files

- `services/static/ext/http/.gitkeep` (template mode — created once, then app-owned)
- `services/static/ext/server/.gitkeep` (template mode — created once, then app-owned)

## New Features

### Sub-app hooks in the static media host nginx config

`services/static/nginx.conf` is core, so sub-apps could not add caching rules, extra locations, or CORS headers to the static host. Two include points now exist:

- `services/static/ext/http/*.conf` — http-level config (maps, upstreams, rate-limit zones)
- `services/static/ext/server/*.conf` — inside the `server` block (locations, headers)

Drop `.conf` files in either directory; the compose file mounts `services/static/ext` into the container.

`X-Content-Type-Options: nosniff` moved from the `location /` block up to the `server` block. nginx drops inherited `add_header` in any block that sets one of its own, so a sub-app location that adds headers must repeat it.
