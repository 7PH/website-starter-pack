# v6.1.0

- **Released:** 2026-11-11
- **Summary:** Apps can add Content-Security-Policy sources in an app-owned `config/csp-ext.ts`, without replacing the whole policy.

## New Core Files

- `app/frontend/config/csp-ext.ts` (template, app-owned once seeded)

Keys are directives, values the sources to add to the core policy. A directive the core doesn't set starts from `'self'`. Read at build time, so rebuild the frontend after changing it. Eg for `YouTubeFacade`:

```ts
export const CSP_EXT: CspExt = {
    'frame-src': ['https://www.youtube-nocookie.com'],
    'img-src': ['https://i.ytimg.com'],
};
```

## Upgrade Notes

No breaking changes. Empty by default, so the policy doesn't change. If you replaced the whole `Content-Security-Policy` in `config/security-headers.ts` to allow a few origins, move them to `config/csp-ext.ts` and drop the override.
