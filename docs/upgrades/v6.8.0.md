# v6.8.0

- **Released:** 2026-11-23
- **Summary:** Scheduled jobs with a cluster lock run on every tick again, plus a batch of fixes from user testing: signup with a taken email, organizations, group links, the header on phones, tab titles and `core-update.sh`.

## Bug Fixes

- **Scheduled jobs with a cluster lock only ran once per backend start** (webhook deliveries, backups, billing, digests). The advisory lock was released on another connection than the one holding it, so every later tick skipped while logging success. Upgrade to get webhooks and these jobs running again
- `ORG_INVITATIONS_ENABLED` was never passed to the frontend, so turning invitations on never showed their screens. If your app added `NUXT_PUBLIC_ORG_INVITATIONS_ENABLED` itself in `docker-compose.yml`, you can drop it
- Signup with a taken email offers "Log in instead" and "Forgot password?" (when usernames are off), and the typed email follows when switching forms
- Pending invitations read "Invited by {name} · expires {date}", in the app's language
- The team list in the account refreshes after accepting an invitation
- The Premium column of the members table only shows when the org is subscribed or a member has a seat
- No more hydration mismatch on `/organizations`
- Opening a group's sign-in link while signed in with a regular account now asks before switching every tab to the managed account. Rename the wording (eg "student") with `core.managed_accounts.switchWarning` / `switchContinue` in your locale files
- The header no longer makes the page scroll sideways on a phone in landscape

## New

- `UPPERCASE_LAST_NAMES` (default `true`, so nothing changes): `false` keeps last names as typed, at signup, Google sign-in and managed account import. Names already stored stay as they are
- `usePageTitle()`: core pages now show "Page · App" in the browser tab. Use it in your own pages too
- `core-update.sh --yes` applies without asking. Any run that applies nothing (`--analyze`, a no, Ctrl-C, an error) leaves `starter-pack-files.txt` as it was

## Upgrade Notes

No migration. Things you may notice:

- App nav items (`main-nav-ext`) show their labels from 1024px wide. Below that they're icons, with the label on hover. If there are more than fit, the nav scrolls inside the header
- `core-update.sh` without a terminal and without `--yes` now stops with an error instead of applying nothing. The upgrade skill passes `--yes` once you approved the plan
- ruff is pinned to 0.17.5 and the core backend is formatted with it: 24 core files change, formatting only. Run `ruff format` with that version on your own code if you want it consistent
