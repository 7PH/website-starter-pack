## Bug Fixes

### Deleted accounts kept being billed

`soft_delete_user` wiped the user's data but left the Stripe customer alone, so an active subscription kept charging a card with no account left to cancel from. A new signup with the same email then took over that orphaned customer, subscription included. Account deletion (self, admin, managed account) now deletes the Stripe customer first, which cancels its subscriptions at once with no refund. If Stripe refuses, the deletion fails with a 500 instead of going through. The account page warns subscribers before they request deletion.
