# v6.2.2

- **Released:** 2026-11-16
- **Summary:** Built Nuxt assets are cached for a year, and their 404s are never cached, so a deploy can't leave a site without CSS or JS behind a CDN.

## Bug Fixes

- The prod nginx sent no `Cache-Control` on `/_nuxt/`. During a deploy, new HTML can ask for asset files nginx doesn't have yet for a few seconds. Behind Cloudflare, those 404s got the zone's Browser Cache TTL and stayed cached at the edge and in browsers. Built assets now get `public, max-age=31536000, immutable` and their 404s `no-store`

## Upgrade Notes

No breaking changes. Rebuild the prod frontend to pick up the new nginx config. Behind Cloudflare, set Caching > Configuration > Browser Cache TTL to "Respect Existing Headers" (see `docs/deployment/reverse-proxy.md`), and purge the cache once if you saw broken assets after a deploy.
