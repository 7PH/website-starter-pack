## Bug Fixes

### Access code sign-in blocked a class sharing one IP

`POST /auth/code` allowed 10 attempts per minute and 100 per day per IP. Schools put every pupil behind one IP, so the 11th pupil joining in class got a 429 even with the right code. The per-IP limits are now 60 per minute and 1,000 per day. Guessing stays blocked by the per-account lockout (5 wrong codes per IP and account, then 15 minutes).
