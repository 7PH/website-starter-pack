# v6.11.0

- **Released:** 2026-11-27
- **Summary:** Small fixes to names, billing and organization settings, a configurable sign-up limit, and the organization billing tab and plan picker can be overridden.

## New Core Files

- `app/frontend/utils/countries.ts`: ISO country codes, named by the browser in the user's language
- `app/backend/tests/test_org_country.py`

## Features

- `REGISTER_RATE_LIMIT_PER_IP` (default 5 per 15 minutes, unchanged). Raise it when many people sign up from one network, eg a class or an office behind one IP
- Component overrides `OrganizationsBillingTab` and `OrganizationsSubscriptionModal` (the second was documented but never wired). Replace the billing tab to hide the seat count or change the upgrade card, eg for an app where premium is org-wide
- `/config` gains `user_plans_enabled`: Stripe is on and `USER_STRIPE_PRICE_IDS` lists a personal plan

## Bug Fixes

- A user with only a first name (or only a last name), eg from Google, showed as their email. The label now uses whichever name is set
- The account page no longer requires a last name to save the profile
- The billing tab no longer offers a personal subscription when the app sells no personal plan (the button opened an empty plan list)
- The billing tab names every organization the user owns, and organizations come back in a stable order (by join date), so "your organization" no longer changes between page loads
- Organization country is picked from a list, named in the user's language, instead of a 2-character text field that cut "France" down to "Fr". The API takes a 2-letter ISO code, case-insensitive, and refuses anything else
- The saved organization address was labelled "Address line 1". It now says "Address"

## Upgrade Notes

No migration, no breaking change. Things to check in your app:

- An organization whose stored country is not a 2-letter code (typed by hand before) can't save its settings until someone picks a country
- `core.organizations.countryPlaceholder` now reads "Select a country", and `core.organizations.address` is new. Apps overriding those keys keep their wording
