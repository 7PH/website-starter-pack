## Bug Fixes

### Header wider than the screen on phones

At 390px, the "Upgrade" link and the user menu label pushed the header to ~508px, so every logged-in page scrolled sideways. Below `sm`, both now show their icon only (the user menu keeps its label as `aria-label`). Wider screens are unchanged.
