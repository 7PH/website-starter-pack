# v6.9.0

- **Released:** 2026-11-23
- **Summary:** Organization members no longer see each other's emails, apps can add Stripe params and point organization links elsewhere, and a batch of fixes from user testing: rate-limit waits, billing details, footer, accessibility and French typography.

## Security

- **Organization members' emails leaked to every member** through `GET /organizations/{id}`. Other members' `email` is now `null` unless the viewer is a site admin or an owner of the org (everyone still gets their own). Plain members also get `null` for `stripe_id` and `stripe_dashboard_url`. Member rows gain `display_label` (display name, username or real name, never a hidden email)

## New Core Files

- `app/backend/src/helpers/stripe_ext.py` (template): `CHECKOUT_SESSION_PARAMS`, `BILLING_PORTAL_PARAMS`, `CUSTOMER_PARAMS`, merged into the Stripe calls. Empty by default. Eg `locale`, or `consent_collection` + `custom_text` for an EU withdrawal waiver (see the file)
- `app/frontend/config/organization-links-ext.ts` (template): point organization links (account cards, billing tab buttons, after creating one) to the app's own page. Null by default
- `app/frontend/components/ui/SkipLink.vue`, `app/frontend/plugins/route-focus.client.ts`, `app/frontend/utils/organization-link.ts`

## Bug Fixes and Changes

- Rate limits: 429s carry `Retry-After` with the real wait, and login, signup and the group link page say it ("Réessayez dans 15 min."). On the group link page, focus goes back to the code field
- `/config` gains `email_enabled`. Without a mail service, signup no longer claims a verification email was sent, and the resend button is hidden
- Billing tab: dates in the app's language, and the plan, its price and the next charge date for a personal subscription
- `npm run start`: the stale image check from v6.6.2 is gone, it reported every built container on Docker's containerd image store. Building before `up` stays
- The default layout's footer scrolls with the page instead of being pinned (the full-height layout keeps it pinned)
- Accessibility: a "Skip to content" link, focus moves to the new page's heading after a client-side navigation, labels on the settings, modal close and icon-only premium buttons, 44x44 header controls on touch screens, account tabs without an empty panel and scrolled to the active one on a phone
- The group link picker lists names alphabetically
- French: "e-mail" everywhere, and a space before the colon in "E-mail de contact :", "Source :", "Dernière mise à jour :"

## Upgrade Notes

No migration. Things to check in your app:

- Code reading `member.email` from the organization detail as a plain member now gets `null`
- The backend now forwards exception headers: an invalid or expired token logs the user out cleanly (the `WWW-Authenticate` check in `useApi` never fired before)
- `UiPageTitleBanner` renders an `h1` (was `h4`), and the org detail's name is an `h2` (was `h1`). Check any styling that targeted those tags
- Layouts you own: give the main area `id="main-content" tabindex="-1"` and add `<UiSkipLink />` first, like the core layouts, so the skip link and the focus after navigation work there
- French strings changed from "email" to "e-mail": an app overriding those keys keeps its own wording
