# v6.9.2

- **Released:** 2026-11-27
- **Summary:** An org plan assigned by a site admin no longer disappears when Stripe has no subscription for it.

## New Core Files

- `app/backend/tests/test_admin_assigned_plan.py`

## Bug Fixes

- An admin-assigned org plan was wiped the first time an org admin opened the billing tab. Stripe has no subscription for that plan, so the sync turned premium off, set the quota to 0 and removed every member's premium seat. Stripe webhooks did the same. While an org has an admin-assigned plan, the billing tab and the webhooks now leave its premium state alone
