# v5.0.2

- **Released:** 2026-09-04
- **Summary:** Patch. Traefik now compresses API responses, the companion to the frontend gzip fix in v5.0.1.

## Upgrade Notes

**No action required.** No schema, API, or migration changes. Only `services/traefik/dynamic.core.yml` changed.

## Bug Fixes

### API responses were served uncompressed

The `/api` router had no compression, so JSON payloads went over the wire raw. A `compress-middleware` is now on that router, with `text/event-stream` excluded so SSE streams still flush immediately instead of being buffered.
