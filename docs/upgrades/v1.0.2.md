# Starterpack v1.0.2

**Release Date:** 2026-03-08

Bug fix release.

## Bug Fixes

### core-update.sh: Template files no longer proposed for overwrite

`:template` files (e.g. `main-nav-ext.ts`) were incorrectly shown as update candidates.
Root cause: `get_upstream_files` was called in a subshell, discarding `FILE_MODES` assignments,
so every file fell back to `sync` mode.

Fixed by populating a global `UPSTREAM_FILES` array instead of printing to stdout, so the
function can be called directly without a subshell.

### ConversationType: Python version compatibility

`ConversationType` changed from `enum.StrEnum` (Python 3.11+) to `str, enum.Enum` (Python 3.9+)
in `app/backend/src/models/conversation.py`.

## Upgrade Notes

No breaking changes.
