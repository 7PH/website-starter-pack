# v5.0.1

- **Released:** 2026-09-04
- **Summary:** Patch. The production frontend Nginx now gzips text responses, which were previously served uncompressed.

## Upgrade Notes

**No action required.** No schema, API, or migration changes. Only `app/frontend/nginx.conf` changed.

## Bug Fixes

### Prod frontend served everything uncompressed

`app/frontend/nginx.conf` shipped with the stock `#gzip on;` line still commented out, so the production container served HTML, CSS, JS, JSON and SVG raw. Gzip is now on for those types, with `gzip_min_length 1024`, `gzip_comp_level 5`, and `gzip_vary`/`gzip_proxied` set so caches and the Traefik hop behave. Images and fonts are left alone.
