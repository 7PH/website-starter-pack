**No action required.** No schema, API, or migration changes. New locale key `core.legal.title`.

## Bug Fixes

### Header nav wrapped on phones

Below the `sm` breakpoint, main nav items show their icon only (the label stays as `aria-label`), so labels like "Mes documents" no longer wrap onto two lines.

### Footer took three lines on phones

Below `sm`, the copyright drops "All rights reserved." and the three legal links collapse into one "Legal" button that opens a popover with them. Wider screens are unchanged.
