# v5.5.0

- **Released:** 2026-11-04
- **Summary:** Apps can declare Premium arranged outside Stripe (invoices, purchase orders, a partner paying), so the header and billing tabs stop selling a subscription on top of it. Checkout errors now show a toast.

## Upgrade Notes

No action required. The upgrade seeds `app/frontend/config/premium-ext.ts`, whose two hooks return `null`, so the UI stays the same until your app fills them in. No migration, no backend change.

## New Core Files

- `app/frontend/config/premium-ext.ts` (template, app-owned once seeded)

## New Features

### Premium from outside Stripe

`config/premium-ext.ts` exports `useUserExternalPremium()` and `useOrganizationExternalPremium(orgId)`. Each returns `{ label, description?, to? }` or `null`. When the user hook returns a value and the user isn't premium yet:

- The header shows the label (a neutral pill, icon only on phones) in place of "Upgrade", linking to `to`.
- The account billing tab shows the notice as the premium source and hides "Subscribe personally".

When the organization hook returns a value:

- The organization's billing tab shows the notice in place of the Stripe Subscribe and Manage billing buttons.
- The admin billing tab shows it above the balance, so admins don't assign a plan on top of it.

## Bug Fixes

### Refused checkouts failed with nothing on screen

The user and organization subscribe actions had no error handling, so a refused checkout (an invalid price, a 409 from an app rule) left the user on the page with no message. They now show a "Couldn't start the checkout" toast.

### E2E job failed on the new GitHub runner image

`ubuntu-latest` moved to Ubuntu 26.04, which Playwright has no Chromium build for. The E2E job now runs on `ubuntu-24.04` (a self-hosted `CI_RUNNER_LABEL` still wins).
