# v3.1.0

- **Released:** 2026-05-03
- **Summary:** Public `/api/v1/config` endpoint with sub-app extension points, dev port parameterization so multiple starterpacks can run side by side, generic LLM provider key mapping, plus large internal cleanup of controllers/composables and a Pydantic v2 / SQLAlchemy 2.0 modernization pass.

## Upgrade Notes

No breaking API changes. Two behavior changes worth noting:

- **Traefik dashboard and backend debug port now bind to `127.0.0.1`** (were `0.0.0.0`). Anyone reaching the Traefik dashboard from another host on the LAN will need an SSH tunnel: `ssh -L 8080:127.0.0.1:8080 user@host`.
- **Default `PUBLIC_URL` now includes `:${PUBLIC_PORT}`**. Sub-apps that override `PUBLIC_URL` in `.env` are unaffected. Sub-apps relying on the default get a URL with an explicit port — drop `:80` / `:443` if you publish behind a TLS-terminating proxy.

### Migration

None.

### New environment variables

Already in `.env.template`:

```bash
TRAEFIK_DASHBOARD_PORT=8080
BACKEND_DEBUG_PORT=5679
```

Override these (and `PUBLIC_PORT`, `COMPOSE_PROJECT_NAME`) to run multiple starterpacks on the same machine.

## New Features

### Public `/api/v1/config` endpoint

`GET /api/v1/config` returns a flat snapshot of feature flags, validation limits, and LLM info. The frontend fetches it once at startup via a Pinia plugin (`useBackendConfig`); on SSR the state serializes into the Nuxt payload so the client rehydrates without a second HTTP call.

Sub-apps extend the payload via the established `_ext.py` pattern: subclass `BackendConfig` and define `build_extra()` in `app/backend/src/schemas/config_ext.py`.

Frontend reads that previously hardcoded backend constants (e.g. `minPasswordLength` in account forms) now read through `useBackendConfig`, so the password-too-short copy interpolates the real limit.

### Generic LLM provider key mapping

The per-provider `if/elif` chain in `helpers/llm.py` is gone. Any LiteLLM provider works out of the box — the env var is derived as `{LLM_PROVIDER.upper()}_API_KEY`. `.env.template` documents OpenRouter as an easy free way to try the LLM features.

### Parameterized dev ports

`TRAEFIK_DASHBOARD_PORT` and `BACKEND_DEBUG_PORT` env vars (with sensible defaults). Combined with `PUBLIC_PORT` and `COMPOSE_PROJECT_NAME`, this lets you run several starterpacks side by side on the same host. `.env.ci` carries the e2e overrides directly, so `docker-compose.test.yml` and the npm e2e script no longer hardcode them.

## Bug Fixes

- `passwordTooShort` i18n string now interpolates the real `{minLength}` from the backend config (was rendering the literal placeholder).
- `useStripe`: all three subscription-reset paths now clear `cancelAtPeriodEnd`. One path previously forgot, leaving the UI in an inconsistent state after a reset.
- `useUnsavedChangesWarning`: the Manual variant duplicated the base composable's option-merge logic, so options got merged twice. Collapsed into the base.
- `migrations/README.md` Adminer URL was pointing at the Traefik dashboard port. Fixed.
- Bumped `envfill` to `^1.2.2`.

## Internal cleanup (no behavior change)

Two large refactor passes shipped in this release. They don't change any public behavior, but they reduce boilerplate and dedupe patterns across the codebase. Sub-apps that copy-paste from starterpack controllers/pages can adopt the helpers if they want; nothing forces them to.

- **Backend** (`-515` lines): or-404 / access-guard / billing helpers across `auth.py`, `users.py`, `stripe.py`, `admin.py`, `conversations.py`, `organizations.py`, `invitations.py`. Stripe-webhook lifecycle (`SessionLocal`/`try`/`except`/`close`) hoisted into `_apply_subscription_event`. `_send_templated_email`, `_encode_typed_token`, `swallow_email_errors`, `ensure_user_cooldown_and_daily`, `get_client_ip`, `register_cron_task`, `issue_jwt_for_user` collapse repeated patterns.
- **Frontend** (`-635` lines): new composables `useScrollToBottom`, `useAdminImpersonation`, `useStoreModal`, `useHashTokenAction`; expanded `useToastHelpers`, `useAuthForms`, `useAccountActions`. Admin list pages wired through `useTableState`. Modals read state via `useStoreModal`.
- **Pydantic v2 / SQLAlchemy 2.0 modernization**: drop v1-style `class Config` for `ConfigDict` across all schemas; `helpers/db.py` switches to `sqlalchemy.orm.declarative_base`. Pytest run is back to 0 deprecation warnings.
