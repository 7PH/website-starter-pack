# v5.1.9

- **Released:** 2026-09-25
- **Summary:** Patch. Prod services now come back after a host reboot or a crash.

## Upgrade Notes

**No action required.** No schema, API, or migration changes. Only `docker-compose.core.yml` changed. The new policy applies the next time the prod stack is started (`npm run start`). To apply it to containers already running without restarting them: `docker update --restart unless-stopped <container>...`.

## Bug Fixes

### A reboot left the site down

Only adminer and umami had a restart policy. `traefik-prod`, `static`, `backend-prod`, `frontend-prod-node`, `frontend-prod-nginx`, `db` and `redis` now use `restart: unless-stopped`, so they return after a reboot or a crash, while `npm run stop` still keeps them stopped. Dev-only services are unchanged.
