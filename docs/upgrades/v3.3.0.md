# v3.3.0

- **Released:** 2026-05-06
- **Summary:** Backend and frontend now expose configuration knobs for non-web clients (e.g. a Capacitor mobile shell that loads the bundled site from a different origin than the API). A new `.env.preview.app` extension point lets sub-apps inject extra env vars into PR preview deploys.

## Upgrade Notes

No breaking changes. Defaults preserve current behavior — apps that don't need either knob see no difference.

### Migration

None.

## New Features

### Configurable API base URL on the frontend

`useAuth.refreshToken()` was the last hardcoded `/api/v1/...` call in the codebase, bypassing `useApi`. It now reads `runtimeConfig.public.apiBase` like every other API call. Set `NUXT_PUBLIC_API_BASE=https://api.example.com/api/v1` (absolute) to point a non-web build at a remote backend. Default is unchanged (`/api/v1`, relative).

### Opt-in CORS origins for production

Production previously had no CORS middleware (same-origin only). A new `EXTRA_ALLOWED_ORIGINS` env var (comma-separated) installs `CORSMiddleware` in prod with those origins when set. Unset → no middleware → identical behavior to v3.2.0.

Example for a Capacitor mobile shell:

```env
EXTRA_ALLOWED_ORIGINS=https://localhost,capacitor://localhost
```

### `.env.preview.app` extension point

PR preview deploys now load env vars from `.env.preview.app` (app-owned, optional) on top of the core preview env. Use this to inject extra config that a sub-app needs in previews without touching the core preview workflow.
