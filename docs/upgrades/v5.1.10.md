# v5.1.10

- **Released:** 2026-09-25
- **Summary:** Patch. Prod builds no longer show "My App" as the page title; the default title now comes from `APP_NAME` at runtime.

## New Core Files

- `app/frontend/plugins/app-title.ts`

## Upgrade Notes

**No action required.** No schema, API, or migration changes. Rebuild the frontend image to pick it up. Check that `APP_NAME` in `.env` is spelled the way you want it shown: it is now the tab title on every page that does not set its own.

## Bug Fixes

### Prod pages showed "My App"

`nuxt.config.ts` set `app.head.title` from `NUXT_PUBLIC_APP_NAME` at build time, and the prod Dockerfiles build without it, so every prod image carried the `My App` fallback. Pages without their own title (for example `/login`) showed it. The default title is now set by a plugin from `runtimeConfig.public.appName`, which `NUXT_PUBLIC_APP_NAME` overrides at runtime. Pages that set a title keep it.
