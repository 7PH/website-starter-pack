# v5.3.0

- **Released:** 2026-09-26
- **Summary:** Minor. The class picker signs a student in from a personal link, so apps can print QR codes.

## Upgrade Notes

**No action required.** No schema, API, or migration changes.

## New Features

### Personal sign-in links for managed accounts

`/c/{share_token}#a=<managed_account_id>&code=<code>` now selects that student, fills the code and signs in. The code sits in the URL fragment, so it never reaches the server or its logs, and the page removes it from the address bar before signing in. A wrong code or an unknown id falls back to the usual picker (with the name selected when the id matches).

Apps build the link themselves, for example as a QR code on printed slips handed to students.
