# v1.1.1 — 2026-04-12

Fix backup command failing when DB password contains shell metacharacters.

## Bug Fixes

- **Backup PGPASSWORD handling**: `run_backup()` injected the DB password directly into a shell string (`PGPASSWORD="{password}"`), which breaks if the password contains `"`, `$`, or backticks. Now passes `PGPASSWORD` via the `env` parameter of `subprocess.run` instead.

## Upgrade Notes

No breaking changes.
