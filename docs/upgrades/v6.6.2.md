# v6.6.2

- **Released:** 2026-11-22
- **Summary:** `npm run start` always swaps in the new build, and fails loudly when a container is left on an older image.

## Bug Fixes

- With some Docker Compose versions, `up -d --build` rebuilt the frontend images but kept the old containers, so prod silently served the previous build. `start.sh` now builds first, then runs `up -d`
- After starting, `start.sh` checks that every prod container runs the current image of its name. Otherwise it names the container, prints the command to recreate it and exits with an error

## Upgrade Notes

No breaking changes, no migration.
