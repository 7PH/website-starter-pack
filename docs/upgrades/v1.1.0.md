# v1.1.0 — 2026-03-11

Add a `pre_login` hook so projects can intercept the login flow without modifying core files.

## New Core Files

- `app/backend/src/helpers/auth_app.py` — template file with a no-op `pre_login` hook

## Upgrade Notes

No breaking changes. The default `pre_login` returns `None`, so existing login behavior is unchanged.

To customize login (e.g. legacy password migration), override `app/backend/src/helpers/auth_app.py` in your project and implement `pre_login`.
